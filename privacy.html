Privacy Policy

Last updated: October 26, 2026

1. YouTube API Services

Shorts Factory uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service. YouTube API Services are provided by Google. See the Google Privacy Policy for how Google handles data.

2. Who uses this tool

This is an internal tool used only by the operator to manage the operator's own YouTube channels. Only the channel owner signs in, through Google OAuth.

3. What data we access

  • Information about the operator's own channels and videos (titles, descriptions, publish status).
  • Public comments posted on the operator's own videos, including the commenter's display name and comment text.
  • YouTube Analytics reports for the operator's own channels (views, watch time, subscribers).

Permissions requested: youtube.upload, youtube, youtube.readonly, youtube.force-ssl, yt-analytics.readonly.

4. How we use the data

  • To upload and schedule the operator's videos.
  • To read comments on the operator's videos and post replies as the channel.
  • To review the operator's own channel performance.

5. How we store the data

  • Data is stored only on the operator's own computer. There is no public server or database.
  • Comment text and commenter names are kept for no more than 30 days and then deleted automatically.
  • OAuth tokens are stored locally and are readable only by the operator's computer account.

6. Sharing

We do not sell, share or disclose YouTube data to any third party. To draft reply text, comment text is sent to an AI model provider (Anthropic). Anthropic processes it only to return the draft and does not receive any account credentials.

7. Cookies

This tool runs on the command line. It does not place cookies or similar tracking on any device. This website does not use cookies.

8. How to revoke access and delete data

  • Access can be revoked at any time on the Google security settings page.
  • To have any stored data about you deleted (for example, a comment you posted on our videos), contact us at the address below. We will delete it within 7 days.
